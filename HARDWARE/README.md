Welcome to minimalistiCE's Hardware repository!
- CAD files are provided in both .stl (ready for 3D printing) and .step (fully editable) formats and are organised according to minimalistiCE’s system taxonomy.
- PCB component guides are available as .pdf files, with the corresponding schematics provided in .dip and .dch formats, also following the same taxonomy.

It is **strongly recommended** that the 3D Printing Guide is read and fully understood before any manufacturing takes place. By proceeding, the user acknowledges that this guide has been read and that all disclaimers in the documentation are understood and accepted.

Any hardware not listed in this repository is not intended to be 3D-printed or assembled, and must be obtained according to minimalistiCE’s Bill of Materials (BOM) and Construction Guide.
