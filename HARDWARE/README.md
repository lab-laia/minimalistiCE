Welcome to minimalistiCE's Hardware respository! All CAD files are available both in .stl (ready to print) and .step (modifiable) formats and are organized according to minimalistiCE's description of systems.

It is **strongly advised** that the 3D Printing guide is read and well understood before any manufacturing. Any hardware not listed here isn't meant to be 3D-printed and should be obtained according to minimalistiCE's BOM.
