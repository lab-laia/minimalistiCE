Welcome to minimalistiCE's Hardware respository! All CAD files are available both in .stl (ready to print) and .step (modifiable) formats and are organized according to minimalistiCE's description of systems.

It is **strongly advised** that the 3D Printing guide is read and well understood before any manufacturing. By proceeding, it is assumed that the 3D Printing guide has been read and that all disclaimers in the documentation are understood and accepted.

Any hardware not listed here is not intended to be 3D-printed and should be obtained according to minimalistiCE's BOM and Construction guide.
