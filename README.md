# Welcome to the minimalistiCE project!

minimalistiCE is a complete equipment for Capilary Electrophoresis (CE) with Capacitevely Coupled Contactless Conductivity Detection (C<sup>4</sup>D) and, best of all, is totally open soruce and mostly 3D-printed!
Here you can find all necessary CAD files, software and all documentation for building and operating the equipment.
